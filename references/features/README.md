# Feature-first reference index

順位（`priority` / `rank`）を残したまま、実装したいUI機能から参照サイトを探せる一覧です。

| ファイル | 機能 | 抽出根拠 |
| --- | --- | --- |
| `cutin-and-page-transition.csv` | カットイン・画面遷移 | Animation / Transitions |
| `fixed-ui-and-navigation.csv` | 固定UI・ナビゲーション候補 | Footer Design / Header Design / Menu - Horizontal / Menu - Vertical / Navigation Menu / Unusual Navigation |
| `background-motion.csv` | 背景演出候補 | 3D / Big Background Images / GLSL / Three.js / WebGL |
| `scroll-driven.csv` | スクロール連動 | Infinite Scroll / Locomotive Scroll / Parallax / Scrolling |
| `microinteractions.csv` | マイクロインタラクション | Gestures / Interaction / Interaction Design / Microinteractions |
| `filters-and-effects.csv` | フィルター・視覚エフェクト | After Effects / Filters and Effects |
| `media-and-sound.csv` | 映像・音声 | Music & Sound / Photo & Video / Sound-Audio / Video |
| `gallery-and-browsing.csv` | ギャラリー・閲覧UI | Gallery |
| `responsive.csv` | レスポンシブ対応 | Responsive / Responsive Design |
| `forms-and-input.csv` | フォーム・入力UI | Forms and Input |
| `unknown.csv` | 未判定 | 機能タグを取得していない既存サイト。機能がないという意味ではありません。 |

`evidence` 列は機能を断定する説明ではなく、公開カタログ上のタグ一致です。実装前にリンク先を確認してください。
